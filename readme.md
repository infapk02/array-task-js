# JavaScript Array Practice

This repository contains beginner-level JavaScript practice tasks focused on **Arrays** and common array methods.

The exercises cover creating arrays, accessing and modifying elements, adding and removing elements, checking array membership, checking whether a value is an array, and combining arrays.

## 📚 Topics Covered

- JavaScript Arrays
- Array Indexing
- Updating Array Elements
- `push()`
- `pop()`
- `includes()`
- `Array.isArray()`
- `concat()`
- `console.log()`

## 📝 Tasks

### Task 01 — Declare an Array

- Create an array containing 5 different fruits.
- Print the 3rd index element.
- Change the 2nd index element to `"jambura"`.
- Print the final array.

**Concepts:** Array indexing, updating array elements.

---

### Task 02 — Add or Remove Elements

- Create an array containing 3 tourist destinations.
- Add a new tourist destination.
- Add two more destinations.
- Remove the last destination that was added.
- Display the final array.

**Concepts:** `push()`, `pop()`.

---

### Task 03 — Checking Array Membership

- Create an array containing different books.
- Use `includes()` to check whether `"Javascript"` exists in the array.
- Print an appropriate message based on the result.

**Concepts:** `includes()`.

---

### Task 04 — Checking if It's an Array

- Create different variables containing arrays and non-array values.
- Use `Array.isArray()` to check each variable.
- Print whether each value is an array or not.

**Concepts:** `Array.isArray()`.

---

### Task 05 — Combining Arrays

- Create two arrays of your choice.
- Use `concat()` to combine them into a new array.
- Print both original arrays.
- Print the combined array.

**Concepts:** `concat()`.
